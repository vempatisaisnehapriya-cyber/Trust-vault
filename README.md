# TrustVault

## About the Project
TrustVault is a personal document management web application developed using Python and Django.

It helps users store, manage, search, download and delete their personal documents.

## Features
- User Registration
- User Login and Logout
- Personal Dashboard
- Document Upload
- Document Download
- Document Delete
- Document Search

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite
- Git and GitHub

## Project Purpose
The main purpose of TrustVault is to provide users with a simple platform to manage their personal documents.
